## Assumptions
- A36-1 (2026-10-20): the orders index had no date range; added Shopify's Date preset filter (`placed`) as a DataTable filter so it lives in the URL like the rest and the export honours it. A custom from/to range was not added.
- A36-2: denials become a quiet 404 everywhere (the admin never admits a page exists to a role without access, matching `requireAdmin`); 403 needs Next `authInterrupts`, not enabled.
- A36-3: export sorted newest first by id (UUIDv7) rather than `placed_at`, so the keyset is exact (JS Dates lose Postgres microseconds).
- A36-4: Fulfilment status is derived from order status (paid/confirmed = unfulfilled, packed, dispatched, delivered).
- A36-5: customers and enquiries exports not added: neither shares the orders filter code, and enquiries has no export permission; each needs its own where-refactor, route, permission and tests (not "a few lines").
