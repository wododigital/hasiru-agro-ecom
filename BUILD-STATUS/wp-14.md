## Assumptions (numbered A14-n, dated 2026-10-20)
1. A14-1 The workbook is read with a small built-in XLSX reader (`seed/lib/xlsx.ts`, zip + sheet XML) because `@tooling/scripts` does not declare `xlsx` and agents add no dependencies. Tested against the real file.
2. A14-2 Woo-only legacy drafts are **125**, not 128: 193 Woo plants - 65 exact - Agarwood - 2 rows that became size variants (Mangosteen 6 ft HA0098, Rambutan N-18 8 ft HA00128). The plan's 128 is 193 - 65 and still contains those three. Self-check asserts 159 + 1 + 7 + 125.
3. A14-3 Matching: the base species is a hard gate and native rows are never matched; propagation is a tie-break only (as a hard gate it broke 8 research-confirmed exact matches such as Anna Apple and Kagzi Lemon). 11 rows are pinned to the research review with a reason each (`PINS` in `match-woo.ts`); a test fails if a pin becomes redundant.
4. A14-4 Images: an exact match uses the image-map gallery when the map points at the same old listing, else that listing's own Woo gallery; non-exact rows use the image map's species photo with `review_notes: ... replace photo`; Agarwood and drafts use their Woo gallery; SaplingMart files are skipped; the 8 Hasiru field photos are added to Amla, Avocado, Guava, Jackfruit, Coconut, Sandalwood and Papaya (x2). Masters are named from the source file (`products/<slug-of-file>.jpg`, `site/<file>`), deduped by sha256. Drafts' galleries are included so a draft can be published without a re-import (44 MB in all, in line with A16).
5. A14-5 Per-product FAQs live only in `faqs.json` (`product_sku` set); `content.faqs` in product records is `[]` (one source).
6. A14-6 Record extras beyond SCHEMA.md: product `data_source` (`client|woo_extra|woo_legacy|placeholder`), `match` ({kind, woo_sku, confidence}), `content.status` (`approved|ai_draft`); input block adds `pack_weight_kg`, `input_type`; testimonials carry `avatar`; counters are `{key,label,value,source,visible,sort}`. `created_at/updated_at` and image `blur` are omitted (importer sets/generates them); images carry `w`/`h` read from the file header.
7. A14-7 Legacy drafts: climate humidity/rain null, temperature parsed from Woo where given, models and compost null, `provenance.identity = "woo"`, `drought_tolerance` null.
8. A14-8 CMS page slugs are the route path without the leading slash (`policies/delivery`, `farm-development/design`, `home`).
9. A14-9 Native rows: name `"Common (Binomial)"` (author citation dropped, English alt name kept as alias), base name = common name, slug `<common without "Native">-native-sapling` (e.g. `sandalwood-native-sapling`); Melia dubia shows as "Malabar Neem (Melia dubia)". "Baraba" is renamed Biriba with a note.
10. A14-10 Template copy (non-Woo rows) is written at seed time from the plant data only (`content.status = ai_draft`, `needs_review`), never by a model; SEO description = first ~155 chars of the short description.
11. A14-11 Woo long descriptions that already contain HTML are kept as HTML (sanitised again on import); copywriting scaffolding ("Product Title:", "Short Description:") is stripped from short descriptions.
12. A14-12 Trust claim wording follows the current site ("Incubated at UASB Bio-NEST, Bangalore"), not the brief's "UAS Dharwad"; asked in CLIENT-QUESTIONS. Counters (850+ acres, 120+ farms, 200+ varieties) are the current site's and `visible: true`.
