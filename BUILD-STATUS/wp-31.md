Worked in `.worktrees/wp-31` on branch `wp/wp-31`. No dependencies added. Files: `tooling/smoke.mjs`, root `package.json` script `smoke`, this file. No module package changes (no small wiring bug found that sits inside a module package and was safe to fix in the time box).

## Usage

```
DATABASE_URL=postgres://localhost:5433/ecomkit_<db> INTERNAL_SECRET=<same as server> pnpm smoke -- --base=http://localhost:3131 [--only=routes,money,jobs,admin] [--strict]
```

- Owner session: `--cookie=`/`SMOKE_COOKIE`, else minted: upserts `smoke-owner@example.invalid` (role owner, `two_factor_enabled`) + an `auth_session` row and signs `ek.session_token` the way better-auth does (HMAC of the token with `derivedSecret('better-auth')`). Verified: `/admin` 200.
- Routes: union of `apps/shop/app/**/page|route` and every `path:` in `packages/*/src/manifest.ts`; dynamic patterns filled from the sitemap tree and from links on admin list pages; one `zz-smoke-missing` slug per storefront pattern must 404 not 5xx; every internal href in returned HTML and RSC payload (cap `--max-links`, default 400) must be non-5xx and non-404. Module routes answering 404 are reported SKIP "not assembled".
- Money: cart API add + quote, place order via the rendered `/checkout` form (no-JS server action post), signed mock PhonePe webhook (`sha256("mock:" + derivedSecret('payments-mock-webhook').hex)`), then DB asserts order paid, stock down, invoice, email + WhatsApp messages, analytics events.
- Jobs: abandoned-cart flow runs, notify-me, enquiry (rendered form incl. guard token), wizard generate/unlock, ERP "Sync stock now" and "Rebuild feeds now" admin forms + run rows, feed served.
- Admin: settings sub-page list + round-trip save, product save, discount create, audit row delta.
- Output: PASS/FAIL/SKIP table, exit 1 on any FAIL (or SKIP with `--strict`), exit 2 when the server is unreachable.

## Assumptions

- Smoke does not advance the clock: abandoned-cart is checked by looking for `cart_abandoned` flow runs (PASS when present, SKIP otherwise); run it after the worker sweep or with the e2e clock helpers.
- Webhook payload shape copied from `packages/payments/src/mocks/phonepe.ts` `orderPayload`; order "paid" accepts `paid` or `confirmed`.
- Column names used in DB asserts (`inventory_level.on_hand`, `notifications_message.channel`, `analytics_event.name/occurred_at`, `core_settings.module/updated_at`, `discounts_code.code`) were taken from schema greps under time pressure and are unverified against a run with data; a wrong one shows as FAIL with the detail, never a crash.
- Admin saves post the page's own server-action form (hidden `$ACTION_ID_*` fields) the no-JS way; forms rendered only client-side cannot be driven and are reported SKIP.
