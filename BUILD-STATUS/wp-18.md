## Assumptions (numbered A18-n, dated)
- A18-1 (2026-10-20) Zones store `district_slugs text[]` and `state_codes text[]`, not `district_ids uuid[]`: the shipping-method contract and the places service speak slugs, and places is optional. `shipping_distance_override` is keyed by `district_slug` for the same reason.
- A18-2 (2026-10-20) Zone resolution: a district listed on any zone beats a state listed on another (then position). No zone or an `enquiry` zone = delivery on request: local and outstation come back unavailable with `shipping.enquiry_only` and an extra `{ methodId: 'enquiry', kind: 'enquiry_only', available: false }` marker is appended.
- A18-3 (2026-10-20) Method kinds are `pickup | local_slot | outstation_distance`; the plan's `flat` kind is not built (the contract's `ShippingMethodKind` has no flat kind, no store needs it now). `zone_id` is nullable: null = any zone of the method's kind (always null for pickup). Per-method knobs live in `rules` jsonb, zod-validated per kind: pickup `readyInDays` (1), local `slotsShown` (4), outstation `minDays`/`maxDays` (5/7).
- A18-4 (2026-10-20) No address yet (cart preview): pickup and zone-less local methods are available, zone-bound local methods and outstation return `shipping.address_needed`.
- A18-5 (2026-10-20) Slot cutoff = hours before 00:00 IST of the slot day, strict (`now < midnight - cutoff`). Default seed 24 h, so Saturday closes at Friday 00:00 IST. `DeliverySlot.remaining` is kg left (Number.MAX_SAFE_INTEGER when the day has no cap); days without room for the order's weight are not offered. Blackout dates are a module setting (`blackout_dates`, comma list).
- A18-6 (2026-10-20) Slot bookings: checkout calls `bookSlot({ orderId, orderNumber, slotDate, weightKg }, { tx })` inside place-order; the row lock is on the `shipping_slot` row(s) for that weekday. `shipping_slot_booking` adds `slot_id`, `order_number`, `reminded_at`, `cancelled_at` to the plan's columns and is unique per order. Shipping releases the booking itself on `order.cancelled` and `order.payment_failed`.
- A18-7 (2026-10-20) `slot.reminder`: job `shipping.slot-reminders` runs hourly 08:00 to 20:00 IST (not once a day) so a booking made on the afternoon before still gets a reminder; each booking for tomorrow (IST) is emitted once (event + `reminded_at` in one transaction, `FOR UPDATE SKIP LOCKED`).
- A18-8 (2026-10-20) Packing: the per-unit default is the line's own `packingFeePaise` (contract input, from `catalog_variant.packing_fee_paise`); rules override it per line (first match by position) and `order` rules add a flat fee once. `quoteMethods` and `packingFee` accept optional `productId` and `sizeClass` on lines beyond the contract so product and size-class rules can match (see request 2).
- A18-9 (2026-10-20) Vehicle choice keeps the plan rule: smallest single fit, else repeated trips of the largest (marked in code as a known ceiling; a mixed fleet can be cheaper just over a capacity). Fill shows at least 1% for a non-empty order; weights compare in grams. Outstation charge rounds km to whole km, one way, no minimum.
- A18-10 (2026-10-20) Distance for outstation: override row first, then `places.getDistrict(slug).distanceKm` through the host binding, else `shipping.distance_unknown` (the order is not quoted, the customer is told the team will confirm).
- A18-11 (2026-10-20) The seed hook reads `data/seed/shipping.json` (money in whole rupees per SCHEMA.md) and seeds each table only while it is empty, so admin edits survive re-seeds; with no file it does nothing and says so. The Hasiru numbers live in that data file, not in the package (request 1).
- A18-12 (2026-10-20) "Small-order bar" is the same meter in a compact one-line form (plan 5.1 cart: "a copy of the truck meter, not a second component"), registered as the `checkout-summary` cart block; the full meter is the `cart` block. Both hide when the selected method is pickup. "Vehicle change" = the meter says "Above C kg the order moves up to a <next vehicle>" for single-trip orders under 90%. The prototype bug where the weight line showed the total instead of the last trip is fixed.
- A18-13 (2026-10-20) Truck-meter copy overrides (e.g. a sample-weights note) go through `configureTruckMeter({ messages })`, since cart blocks receive only `CartBlockProps`.
- A18-14 (2026-10-20) PDP delivery check is a shipping `pdpSection` (aside, order 50) with a client island calling `/api/delivery-check` with the pincode and 1 kg; a pincode needs the host's `resolvePincode` binding (places directory), otherwise the island shows the "choose your district at checkout" message.
- A18-15 (2026-10-20) IST date helpers (`istDate`, `addDays`) are written in shipping's domain: core has none, and analytics (`istDay`) and admin-shell (`istDate`) each keep their own copy already (request 4).
- A18-16 (2026-10-20) Shipping quotes are not cached (five small indexed reads per quote); marked in code with the upgrade path.
