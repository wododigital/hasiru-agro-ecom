## Assumptions
- A12-1 (2026-10-20) "beacon < 3 KB" is the gzip transfer size (2.3 KB; research says "<3 KB gzip"). Raw is 4.3 KB; the test caps raw at 5 KB so growth is noticed.
- A12-2 (2026-10-20) `analytics_session` gains `channel text` and `bot_name text` (plan columns kept). Needed for Traffic and Bots tabs without reclassifying in SQL.
- A12-3 (2026-10-20) `analytics_event` primary key is `(id, server_ts)` (a partitioned table's unique keys must contain the partition key). Partitions are UTC calendar months.
- A12-4 (2026-10-20) Idempotency: unique `(client_event_id, server_ts)` cannot catch a retry (server_ts differs), so ingest skips ids already stored in the last 7 days under a per-visitor advisory lock. Tested with concurrent replays.
- A12-5 (2026-10-20) Test sessions = staff viewers or any event with `test: true` (orders must add `test: true` to the purchase `track()` of a test order). Bots and test sessions are stored, excluded from all reports except Bots.
- A12-6 (2026-10-20) Visitor cookie `ek_vid` is always set (aggregate first-party analytics); only identity linking needs `analytics_identity` consent. Without a `hasConsent` lookup nothing is linked (fail closed).
- A12-7 (2026-10-20) `src/domain/sources.ts` names AI crawlers and assistant hosts (ClaudeBot, claude.ai, copilot.microsoft.com, anthropic-ai UA) because classification must match them. These are third-party data strings, not tool mentions; the gate's forbidden-name scan should allowlist this one file.
- A12-8 (2026-10-20) Bots tab shows only agents that run the collector; crawlers that never run JS are not recorded (would need a per-request write in proxy.ts).
- A12-9 (2026-10-20) Rate limit default 300 batches per IP per minute (mobile carrier NAT shares IPs); `createBeaconIngest({ ratePerMinute })` changes it. No module settings were added.
- A12-10 (2026-10-20) The three app files are hand-written (no generated header) so `modules:sync` keeps them whether or not analytics is enabled yet; they match the manifest routes.
- A12-11 (2026-10-20) Funnel is sequential per session (each step's first time must not precede the previous step's). CLS is a plain sum without session windows (`ponytail:` note in beacon.ts).
- A12-12 (2026-10-20) `apps/shop/app/(admin)/admin/analytics/page.tsx` imports `../../../../src/generated/registry` with an eslint-disable line: the boundary pattern `../../../*/src/**` also matches the app's own deep relative import.
