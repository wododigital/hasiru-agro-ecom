## Assumptions
- A01-1: `--color-muted` is the earth tone darkened to `#6e5a42`; the plan's `#8B7355` is 4.1:1 on cream and 3.7:1 on cream-dark (fails AA, would break the accessibility >= 95 budget).
- A01-2: added tokens `--color-primary-hover` (forest-light), `--color-primary-strong` (forest-dark), `--color-ring`, `--color-overlay`; tint variants use Tailwind opacity modifiers (`bg-success/12`) instead of more tokens.
- A01-3: Tailwind's default colour palette is disabled (`--color-*: initial`) so only semantic colours exist as utilities.
- A01-4: the `@source` glob is `'../../../packages/*/src/**/*.{ts,tsx}'`. The CONVENTIONS form `'../../../packages/*/src'` silently matches nothing (verified: zero utilities generated).
- A01-5: DataTable paginates on the server (URL `page`) instead of virtualising over 200 rows; no list renders more than one page.
- A01-6: Select, Checkbox, Segmented and DateRange are native inputs (phones, no-JS, no picker library). Sheet is the radix Dialog with an edge `side`; `vaul` is not used.
- A01-7: the stories page is dev/test only: `notFound()` in production unless `ENABLE_MOCKS=1`. It renders inside the admin layout, so it will need a staff session once WP-08 gates `/admin`.
- A01-8: added primitives beyond plan 2.3 that later modules would otherwise fork: Textarea, Checkbox, Segmented, BarChart (plan 4.3).
- A01-9: header, footer, cart drawer and consent banner markup are not WP-01 (WP-00a's request routes them to WP-28); WP-01 ships their copy keys in `messages/en.ts` and the primitives (Sheet, StickyBar, ToastRegion).
- A01-10: `[data-surface='shop']` re-applies the store theme inside admin pages (used by the stories page).
